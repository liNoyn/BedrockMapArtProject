# 全方式の精度強化：第1段階（2026-10-24）

GUIのイラスト・バランス・ブレンド・ディザなしに加え、保存データとCLI向けの旧方式を含む
全17 `DitherMode` を比較対象とした。作業開始時の未コミット変更を含むCoreとパレットを保存し、
同じ計測コードから改善前後を呼び出した。HEADとの差を改善前の代わりにはしていない。

## 採用した変更

- 高さ制限の動的計画法で、散らし用乱数を色誤差から分離。本来の色誤差が完全に等しい場合だけ
  二次評価に使う。以前の微小加算では「同点」の範囲を超えて、正確な色まで別の色に変更していた。
  再現例（暗色 `#FEFFFF`、通常色・明色 `#FFFFFF`、64×1）では、原色を保つ画素が31/64から64/64へ改善。
  小さい列について全実行可能な陰影列を列挙し、5種類の色距離・陰影ペナルティ・透明穴を含めて
  DPの結果が最小コストと一致することをテストした。
- 輪郭重みをOklabのL/a/b各成分のSobel勾配から計算する。
  以前の `L + 0.5 * chroma` では、明度・彩度が等しく色相だけ違う境界が消えていた。
  色相平面の回転に対する不変性と透明画素の除外を単体テストで確認した。
- 反復処理は少数の変更が残っているだけでは収束扱いにしない。変更ゼロか設定済み上限で終了する。
  全画像の大域最適解を保証するものではない。
- イラスト方式の最適化を2ラウンドに増やし、交換後の再最適化を行う。
  候補色・静かな配色を選ぶ評価式は維持する。
- Lab/Oklabの最近傍探索に厳密なk-d treeを導入。候補順による同点優先、陰影マスク、ペナルティを保持する。
  探索木・色座標は並列ワーカー間で共有し、結果キャッシュは個別に持つ。
  小さいパレットや他の色距離は従来の全候補探索を使う。近似検索にはしていない。

探索木だけを導入した段階では、17方式816条件の出力PNGと入力PNG、計828枚が導入前とSHA256一致。
別途、重複色を含む251候補に対して2色距離・4ペナルティ・計2400クエリを全候補探索と照合した。

## 比較結果

合成10画像と既存のastronaut/coffee画像を使用。同じパレット、Important支持、地図グリッド配置。
48/96ではFlat・Classic・Valley・Valley高さ4、128では7画像のValley・Valley高さ4。
各条件3回の変換時間の中央値を使い、以下の時間は条件間の平均。品質は既存のCIEDE2000多尺度指標で、小さい方がよい。

|128×128・14条件/方式|総合誤差 前→後|時間 前→後（ms）|
|---|---:|---:|
|イラスト|5.340346 → 5.336484|62.85 → 64.09|
|ブレンド|4.474091 → 4.473949|57.86 → 57.91|
|バランス|5.024573 → 5.024434|75.73 → 70.70|

改善は小幅で、全画像・全距離で一律改善したわけではない。
96の48条件/方式ではイラスト6.002654→5.996544、ブレンド4.877306→4.877331、
バランス5.683518→5.683638。輪郭保護と各方式の評価式は、総合指標だけとは一致しない。
ディザなし等の高さDPもOklab二乗誤差を最小化しており、CIEDE2000総合値の改善を保証しない。
48でディザなしの高さ4を確認したところ、12画像すべてで元のOklab目的関数は悪化していない。
通常の誤差拡散6方式は出力を維持し、48条件平均の時間がこの測定では約12〜14%短縮した。
小画像のディザなしや一部の規則ディザは準備処理等により遅くなっている。
時間はこのWindows/.NET環境での記述的測定であり、他環境での保証ではない。

## 採用しなかった設定

ブレンドを候補32・12パス・交換3パス・3ラウンドにした実験では、96の総合誤差が
4.877306→5.039646と悪化し、時間も31.65→51.49ms。遠距離だけを重視して採用しなかった。
候補を20へ戻して反復のみ増やす設定も、総合4.876524に対して41.48msを要し、
バランスでは改善しなかったため既定には採用していない。比較出力は残してある。

## 成果物・次の検討

最終設定で全311テスト合格（Core 302＋GUI 9、新規10件）。通常のReleaseビルドは警告0・エラー0。
全17方式について5画像×高さ2/4/8/16×配置2通り×支持2通り、計1360条件で高さ上限と陰影再現が合格。
48/96/128の比較でも、不透明画像の配置後の色不一致・地形依存・不安定ブロック・高さ超過は0。
Minecraft実機での新たな見え方の検証はまだ行っていない。

`artifacts/codex-reviews/2026-10-24-precision/` に開始時の `baseline/`、探索高速化後の `phase1/`、
全方式48比較、主要方式96/128比較、採用しなかった `deep96/`・`repeat96/`、
`comparison.json`、`exact-search-image-check.json`、旧不具合の再現用 `probe/` を保存。
`Compare.ps1` は同じシーン・方式・地形・高さ条件を突き合わせ、不透明画像の陰影や高さの不整合を拒否する。
透明穴のあるalpha画像の地形依存は従来からあり、不透明画像と区別している。

今回で全方式の最高精度が達成されたとは判断していない。Knollの混色計画、規則ディザの振幅、
イラストの量子化された混色計画、候補探索の精度と粒状感の両立、より大きな画像と制限パレットでの評価は
引き続き検討が必要。
