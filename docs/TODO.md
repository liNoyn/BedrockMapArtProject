# Bedrock Map Art Project — 今後の開発・検証 TODO

確認時点: 2026 年 10 月 18 日 / v0.11.1　状態: 今後実施予定（現時点では保留）

## 1. 現在の到達点

BMAP では、Minecraft Bedrock Edition 専用のマップアート生成機能を実装済み。

- C# / Avalonia によるデスクトップ GUI
- 79 色セット・355 ブロックのパレット
- 画像編集・多数のディザリング方式、Optimised Dithering（2 色・3 色混合）
- Flat / Classic / Valley 建築方式、高さ制限・高さ最適化
- 2D・3D プレビュー、建築ガイド・素材集計、.mcstructure 出力
- 地図 RGBA の読み取り専用キャリブレーション、地図シミュレーター・陰影解析
- 日本語・英語 UI

実測によって確認できたこと:

- Bedrock 1.26.51: 段差 ±1 は座標の偶奇で陰影が変化、±2 以上は常に明暗、東西の段差は影響なし、
  陰影倍率 180 / 220 / 255、基本色 × 倍率 / 255 の整数切り捨て。陰影テストパッド 8,032 点で checker モデルが完全一致。
- Bedrock 1.21.132〜1.26.51: 保存された 12 枚の地図（約 19 万ピクセル）を解析し、13 色セットの基本色を確認。

これらはリポジトリに記録された測定結果であり、すべてのゲームバージョン・ブロックについて検証が完了したわけではない。

## 9. 開発再開時の方針

新機能の追加よりも、ゲーム内との完全一致を優先する。

Bedrock 1.26.51 における通常ブロックの段差と陰影計算は、実測によって高い精度で再現できている。一方、ブロックごとの
基本地図色・特殊ブロック・バイオーム・水・構造物出力の実機互換性には未検証部分が残る。

次に開発を再開するときは、まず色テストパッドと .mcstructure の実機検証を進め、その結果に基づいて色パレットと
計算規則を更新する。

最終目標: Minecraft Bedrock Edition が実際に描く地図を、可能な限りピクセル単位で正確に再現するマップアート生成ツールにする。
