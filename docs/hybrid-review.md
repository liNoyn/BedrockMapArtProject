**Hybridレビュー・比較検証 — 2026-10-24**

対象は `294c14c` と `35e8ae5` のHybrid追加・単色判定改善。調査開始時の作業ツリーはクリーン。
変更前HEAD `35e8ae5` を別ディレクトリへ展開し、同一のベンチマークから修正前後を測定した。
修正と再現可能な比較ツールをローカルへ追加した。コミット・公開は行っていない。

Hybridは、単色をOptimizedの結果に固定して残りをPerceptualで最適化する構成として成立している。
ただし、空の緩い勾配の誤判定、独自Refine設定での固定解除、強さ0の挙動、不要な二重処理に改善が必要だった。

| 重要度 | 所見 | 修正・検証 |
|---|---|---|
| P2 | 空の緩い1方向勾配で、垂直方向の傾きが水平の差0の近傍で薄まり、大きな「単色」領域になる | 8/16画素離れた方向別の変化も評価。96×96の空サンプルの固定対象率は99.26%→0%、Valleyの遠距離色差は1.825→0.788 |
| P2 | `Refine`の固定画素でも、PairListsが初期候補へ置き換えることがある | 固定画素を候補リストの構築・再割当てから除外。独自PairLambda設定による失敗を修正前テストで再現 |
| P2 | Hybridは強さ0でも両モデルを動かし、ディザなしと異なる結果になる | Perceptualと同様、独自Refine指定がない強さ0はNoneへ切替。修正前の失敗を再現 |
| P2 | 単色領域が0%でもOptimizedを全実行し、100%でもPerceptualを実行する | 分類を最初に1回だけ行い、不要なモデルを省略。素材種類を減らす再計算でも分類を再利用 |
| P2 | Hybridだけ高さ探索の各試行で二段階の精密化を実行する | 制限時は陰影を保持する性質を使い、FSで探索して最終試行だけHybrid。素材数制限がある場合は精密モデルで探索を継続 |
| P2 | `FlatAreas`単体の前処理はアルファしきい値より薄い画素のRGBも取り込む | しきい値でマスクしてからノイズ除去。空白RGBへの独立性を検証 |
| P3 | 単色領域の連結探索で画素ごとに4近傍配列を確保し、分類中のキャンセルにも未対応 | 配列確保を除去。ノイズ除去・分類・連結探索・成長へCancellationTokenを伝播 |
| P3 | CLI `bench`の比較にHybridがなく、高さ付き比較も生のQuantizerだけを測定する | Hybridを追加し、支えと配置条件を含むHeightPlannerを使うよう統一 |

追加で、高さ探索後の最終レイアウトを確認し、必要なら探索量を下げて再生成する防御を入れた。
素材種類の削減で最終パレットが変わる場合にも上限確認が行われる。既存コードでの上限違反を再現したという所見ではなく、検証の強化である。

固定した画素の残差を周辺へ伝播しない方針は維持した。これによって残りの画素が単色面の色差を埋め合わせる縁取りを抑える。
全画素の混色色差を最小にする目的関数とは異なる、Hybridの見た目を優先する選択である。矛盾していた引数コメントも修正した。

**比較条件と結果**

合成8種（勾配、空、単色イラスト、混在、肌色、質感、透明境界、一様な色）と写真2枚。
同じパレット、強さ1、Important支え、地図グリッドに合わせる配置で測定した。
96×96でFlat / Classic / Valley / Valley上限4を比較し、3モデル×40条件＝120条件。
JIT・ワーカーのウォームアップ後に各変換を3回実行し、その中央値を記録。下表の時間は40条件の中央値の平均。
高さ探索は計測内、地図シミュレーション・画像保存・画質評価は計測外。実行順は画像・条件ごとに回転した。
環境はWindows 10.0.26200、.NET 8.0.32、論理プロセッサ12。

| 修正後モデル | 画素ΔE | 近距離ΔE | 遠距離ΔE | 総合 | 粒状感指標 | 時間 |
|---|---:|---:|---:|---:|---:|---:|
| Optimized | 9.545 | 5.254 | 4.353 | 6.101 | 7.658 | 40.68ms |
| Perceptual | 11.432 | 3.144 | 2.294 | 5.003 | 13.078 | 31.61ms |
| Hybrid | 10.809 | 4.284 | 3.470 | 5.711 | 9.588 | 32.83ms |

ΔEはCIEDE2000、近距離/遠距離はリニア光でσ0.8/2.0のぼかし後に評価。
総合は画素25%・近距離50%・遠距離25%。粒状感指標はOklab量子化残差の隣接差のRMS×100。
いずれも小さいほど低誤差・低変動だが、粒の少なさと混色の正確さは別の性質として読む。
平均に一様な色や単色イラストも含むため、平均の総合値だけで見た目の優劣は決められない。

Hybridの変換時間は同じ96×96の40条件平均で79.77→32.83ms（約59%減）。
実際の1枚の地図と同じ128×128でも、勾配・イラスト・写真2枚、Valley無制限/上限4の8条件を各3回測定した。

| 128×128、8条件平均 | 修正前 | 修正後 |
|---|---:|---:|
| Optimized | 65.77ms | 75.37ms |
| Perceptual | 55.53ms | 56.73ms |
| Hybrid | 162.70ms | 82.61ms |

128×128ではHybridが約49%短縮した。単色・勾配の割合でコストが変わり、部分的に単色がある写真は両モデルを使うため高くなる。
3回の中央値による実機測定で、処理時間にはJIT・GC・機器状態による変動が残る。すべての画像で同率の高速化を保証する数値ではない。

画質の具体例（96×96、Valley無制限）:

- 一様なイラスト: HybridはOptimizedと同じ画素値。粒状感1.483に対しPerceptualは12.629。
- 混在画像: Hybridの遠距離色差2.821・粒状感7.100。Optimizedは3.431・5.929、Perceptualは0.970・12.860。
  Hybridは単色部分の均一さを維持するぶん、Perceptualより混色色差が大きい。
- astronaut / coffee: この解像度の修正後分類では単色領域がなく、Hybridの出力はPerceptualと同一。
- 空: 方向別の長い距離の判定で誤固定を解消し、HybridがPerceptualと同じ階調を生成する。

**高さ制限**

上記120条件では色の不一致0、落下/脱落0、予算付きの30条件で高さ超過0。
透明境界画像では北隣が空白の画素を地形依存として記録している。空白を含む結果を実ゲームでの完全再現と断定しない。

別に、混在画像と写真2枚 × 上限2/4/8/16 × 配置グリッド有無 × Important/AllDouble支え × 3モデルの144条件を検証。
全条件で上限内・地図シミュレーターとの一致・落下/脱落0を確認した。
各予算/モデルの12条件平均の遠距離ΔEは以下。

| 高さ予算 | Optimized | Perceptual | Hybrid |
|---|---:|---:|---:|
| 2 | 3.222 | 2.012 | 2.379 |
| 4 | 3.053 | 1.936 | 2.283 |
| 8 | 2.926 | 1.852 | 2.202 |
| 16 | 2.760 | 1.712 | 2.080 |

ここで上限は既存仕様の最大Y差。最低Y=0から占有するブロック層数は最大Y+1となる。
追加の回帰テストでは素材種類上限2/4、グリッド有無、支え付きの条件も扱う。
モデル間の差が小さくなる高さ上限でも、Hybridの陰影固定と生成レイアウトの整合性は保たれた。

**モデルの整理と次の改善**

今回はモデルを削除しない。Optimizedは均一さ、Perceptualは混色精度、Hybridは混在画像での領域別の制御に用途があり、
画質・粒・速度の全軸で常に劣るモデルはこの3方式の間にはなかった。既定はユーザー変更時のOptimizedを維持した。
従来の誤差拡散・規則パターン方式については今回の3モデル比較から削除を判断しない。保存済みプロジェクトの列挙値も維持する。

次の改善候補は、Hybridの固定領域を確認するプレビュー、画像解像度に対する最小領域150画素の扱い、
圧縮ノイズの強いイラストでの分類、部分的に単色を含む大型画像で片側モデルを局所的に計算する方法。
現在の判定はしきい値に基づくため、すべての写真・イラストを正確に分類する保証はない。

**追加修正（2026-10-24、レビュー確認時）**

空の誤判定対策で加わった 8/16 画素先の傾き判定が、輪郭のにじみ画素や、輪郭をはさんだ似た色の面（クリーム色の顔と
クリーム色の背景など）とも比較していた。そのためイラストの単色面の多くが「グラデーション」と判定され、合体モードで
粒が戻っていた（手元の合成イラストで単色判定: 髪と顔 85%→28%、パステル 89%→65%、紫の円が判定外）。

- 遠い比較相手は、それ自体が局所的に平らな画素に限定した（にじみ画素を除外）。
- 比較の途中で隣どうしの色が 0.015 を超えて変わる場合（輪郭をまたぐ）は比較しない。量子化された空は 1 段ずつしか
  変わらないので判定は残る。

結果: 単色判定は髪と顔 85%・クロミ風 90%・パステル 89% に戻り、空・グラデーション・写真は 0% のまま。
回帰テスト `FlatAreas_NextToASimilarAreaAcrossAnOutline_StayFlat`（修正前は顔の 36% しか単色にならず失敗）を追加。
