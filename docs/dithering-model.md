**ディザリングモデル再構築 — 2026-10-24**

新しい `DitherMode.Perceptual`（GUI名: 高精度）を選択肢として追加した。既定は従来の `Optimized` のまま（2026-10-24 にユーザーが判断）。
元画像の局所的な混色を優先するモデルで、グラデーションや写真に強い一方、単色の淡い面には粒（白い点など）が出やすい。
既存の列挙値は変更せず新モデルを末尾に追加したため、以前の明示的な方式設定は維持される。

**モデルの構成**

1. パレットと建築方式から実際に使える地図色を作る。
2. リニア光のFloyd–Steinbergで初期解を作る。誤差補正された小数RGBを整数に丸めず候補を比較する。
3. 各画素に対し、元画像にOklabで近い最大20候補を用意する。高精度モデルは従来モデルの2色・3色プランによる制限を使わない。
4. 画素の置換と隣接画素の交換で、多尺度の二乗誤差と知覚的な画素誤差を減らす。
5. 高さ制限・陰影ペナルティがある場合は、各画素の陰影を固定して色だけを変更する。

多尺度部分は次の離散モデルで評価する。

`E = p·||e||² + w1·||G1*e||² + w2·||G2*e||² + Σ perceptualCost(i, colour_i)`

`e` は作業色空間の出力−目標。既定ではリニア光に暗部の重みと色成分の重みを適用する。
`G` は ±ceil(3σ) で打ち切り、総和1に正規化した有限ガウスフィルター。
誤差の画像外・空白画素は0とし、畳み込みの出力は周囲のパディングも含めたエネルギーとして定義する。
知覚項はOklab距離に基づき、輪郭では画素誤差の重みを増やす。

従来の連続ガウス自己相関のサンプリングを、`C = p·I + w1·G1ᵀG1 + w2·G2ᵀG2` の実際の離散自己相関へ置き換えた。
小さいσ、σ1>σ2、σ=0でもフィルターの意味が保たれ、自己相関の中心と交換項が同じ目的関数に従う。
数学上は半正定値で、実装上は浮動小数点精度内で扱う。局所探索なので大域最適解の保証はない。

強さ1の既定値:

| 項目 | 高精度モデル |
|---|---:|
| 画素のリニア誤差重み | 0.015 |
| Oklab画素誤差重み | 0.025 |
| σ / 重み | 0.8 / 1、2.0 / 1 |
| 色成分の重み | 2 |
| 暗部の重み指数 | 0.35 |
| 輪郭の追加重み | 0.4 |
| 候補数 | 最大20 |
| 置換 / 交換 / ラウンド | 最大8パス / 2パス / 2ラウンド |
| 前処理のノイズ除去 | なし |

強さを下げると画素誤差の重みを増やす。強さ0では、明示的な独自Refine設定がなければディザなしへ切り替える。
従来モデルはその既存の混色方針を維持するが、共通の離散カーネルと小数精度の改善によって出力が完全に同一になる保証はない。

**共通処理の修正**

- Knollは6bit/チャンネルのバケット中心による近似から、正確な24bit入力色でのプラン生成へ変更。
  プランキャッシュを各Matcherで最大4096件に制限した。キャッシュの上限や処理順は結果に影響しない。
- Knollの強さ0はディザなしと同じになり、パレットに完全一致する一様な色はそのまま保持する。
- アルファしきい値以下の画素は、前処理・候補プランでも同じ空白として扱う。
  空白に隠れたRGBを変えても可視部分へ影響しないようにした。
- 混色プランと画質評価で使うぼかしは、マスク付き分子とマスクを両軸で畳み込み、最後に正規化する。
  行ごとに途中で正規化する方式では、不規則な透明境界の周囲に偏りが出るため修正した。
- QualityScoreは画像寸法の不一致を拒否する。
- HeightPlannerは新モデルの初期解と強さ0の挙動を区別し、支えを含む実配置で高さ上限を確認する。
- GUIの日本語・英語表示、CLIのbuild/analyze/convert/benchへ新モデルを接続した。

**旧モデルとの比較**

96×96の合成画像7種（色勾配、淡色、肌色、暗部、細線、質感、透明境界）を、FlatとValleyの2方式で比較した14条件の単純平均。
旧側は変更前HEAD `965cb43` のソースから別にビルドして生成した。
両側の保存画像を、修正後の同じQualityScoreで再評価している。透明境界の評価式だけが変わることによる見かけの改善は含めない。

| 指標（ΔE2000、小さいほどよい） | 変更前Optimized | 新Perceptual | 変化 |
|---|---:|---:|---:|
| 画素単位 | 10.664 | 12.335 | 15.7%増加 |
| 近距離（σ0.8のリニアぼかし） | 4.988 | 3.316 | 33.5%減少 |
| 遠距離（σ2.0のリニアぼかし） | 3.980 | 2.497 | 37.3%減少 |
| 総合（画素25%・近距離50%・遠距離25%） | 6.155 | 5.366 | 12.8%減少 |

この比較では14条件すべてで総合値が改善した。
ただし、画素単位の色差は増えている。近くで拡大したときの粒や色の散らばりよりも、少し離れたときの元画像の色・階調を優先するモデルになっている。
一様な面の穏やかさを優先する場合は従来Optimizedを選ぶか、強さを下げる。
写真・イラスト全般での優位性を保証する測定ではなく、合成画像の比較結果である。

処理速度は入力色数・建築方式に依存する。特にKnollは正確な入力色からプランを作るため、旧バケット方式より遅くなる場合がある。
今回の比較時間は単発測定なので、速度向上率は主張しない。

`dotnet test BMAP.sln -c Release --no-restore -p:BundleTextures=false --verbosity quiet`

全225テスト合格（今回15件追加）。Releaseビルドは警告0・エラー0。
新規検証には、直接畳み込みと離散二次形式の数値的一致、マスク付き2次元畳み込みとの照合、小数入力の最近傍比較、
Knollの強さ0と完全一致色、隠れたRGBからの独立性、高さ制限2/4/8、強さ0での高さ制限、再現性、キャンセルを含む。
比較用と解像度の異なるグラデーションでも、旧モデルより近距離・遠距離・総合の色差が低いことをテストする。
以前の淡いピンク・淡紫・圧縮ノイズなどの見た目の回帰テストも合格した。
