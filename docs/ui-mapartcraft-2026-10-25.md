# MapartCraftを参考にしたGUI整理

参照：[MapartCraft 日本語版](https://rebane2001.com/mapartcraft/ja)。
画面構成・色・操作の並びを参考にし、サイトのコードや画像はコピーしていない。

## 変更内容

- 実機キャリブレーションのパネル、校正プレビュー、対応するViewModel・コマンド・表示文言を削除。
- 陰影・建築チェックのパネル、判定表示、陰影解析プレビューを削除。
- 変換や手直しのたびに実行していたバックグラウンドのチェックを削除。
  3Dメッシュもチェック結果に依存せず作成する。
- 左にブロック選択、中央に正方形の画像選択・プレビューと材料、右に設定と緑の出力ボタンを配置。
- チャコールの背景、白い入力欄、大きな見出し、色別のブロックボタンに調整。
- 材料一覧はブロック名・数量を中心にし、所持数・不足数・建築進捗を折りたたみに整理。
- 高さ分析は「その他」の中へ移動。通常の設定から出力までを見渡しやすくした。
- 幅が足りないウィンドウではワークスペースを横スクロールでき、設定欄が操作不能にならないようにした。

建築の陰影計算、高さ制限、3D表示、mcstructure出力は引き続き利用できる。
開発・実測用のCore/CLIと既存の色プロファイルは削除対象に含めていない。

## 入力欄の表示修正

- 高さの数値欄を112pxにし、左右に並ぶ上下ボタンを非表示にした。111・383など3桁の数値を入力中も全文表示する。
- 通常・ホバー・フォーカス・無効状態の入力色をウィンドウ内で統一。
  Fluentの状態別ブラシも上書きし、NumericUpDown内のTextBoxや選択欄に黒背景・濃色文字が混在しないようにした。
- キャレットと選択中の文字色も濃色にした。
- Windows上で111・383の入力と、プロジェクト名にフォーカスがある状態の表示を確認。
