# 混色計画・完全一致色の精度強化（第2段階）

第1段階の最終Coreスナップショットを比較基準に、全17方式を調べた。
主な問題は、パレットで表現可能な色にも不要な誤差を入れていたことだった。

## 修正

規則ディザ（Bayer2/4/8、Ordered3、BlueNoise）は、陰影ペナルティを含めて選ばれる候補が元色と
完全一致する場合、ノイズを加算しない。高さ制限のDPでも同じ判定を行い、制約下の色選択を保つ。
ペナルティで別の陰影を優先する設定を無視して、完全一致へ強制する処理にはしていない。

イラスト方式の混色計画は5bitの色バケットを共有するため、元の画素が持つ正確な色を
候補から落とす場合があった。元画素に対する候補を追加できるようにし、バケット計画と同じ
色相・彩度・明度の評価を共有する `MixTarget` にまとめた。高さ制限中の陰影とHybridの固定画素は保つ。
単色を選んだ計画は、完全一致色を復元する場合以外には候補を増やさない。
既に混色する計画に限り、既存候補より評価のよい元画素の候補を追加できる。

## 完全一致色の検証

既定パレットの到達色を全件使用。Flatの79色、Valleyの237色を各8×8の単色画像にし、17方式で変換した。
失敗件数は「64画素のうち一つ以上が元色と異なった単色画像」の数。

|方式|Flatの失敗 前→後|Valleyの失敗 前→後|
|---|---:|---:|
|Bayer2|55 → 0|211 → 0|
|Bayer4|66 → 0|230 → 0|
|Bayer8|67 → 0|233 → 0|
|Ordered3|63 → 0|226 → 0|
|BlueNoise|67 → 0|232 → 0|
|イラスト|2 → 0|22 → 0|
|その他11方式|0 → 0|0 → 0|

合計5372条件で、失敗1474→0。さらに通常陰影の全79色×17方式（1343条件）を高さ2の支持付き配置で検証し、
完全一致・高さ上限・シミュレーターの陰影再現を確認した。到達不能な色や制約により使えない陰影まで
完全一致を保証するものではない。

## 通常画像の比較

第1段階と同じ12画像・4地形/高さ条件・3回計測を使用。総合値は既存のCIEDE2000多尺度指標で、小さい方がよい。

|96×96・各48条件|総合誤差 前→後|画素誤差 前→後|
|---|---:|---:|
|イラスト|5.996544 → 5.993261|8.930315 → 8.926347|
|バランス|5.683638 → 5.683572|10.000175 → 10.000180|
|ブレンド|4.877331 → 4.877331|10.700559 → 10.700559|

128×128の7画像×2条件では、イラストの総合5.336484→5.335848。
バランスとブレンドは同じ出力だった。通常画像の改善は小幅で、画像・距離ごとに一律改善したわけではない。
規則ディザには元色の照合が増えるため、小画像では処理時間が増える条件もある。
時刻・環境負荷の違う比較で、出力を変えていない方式にも時間差が出ており、速度向上の根拠には使っていない。

## 採用しなかった案

- 元画素の単純な最近傍色を常に候補へ追加する案は、96のイラスト総合値を5.649655まで下げたが、
  淡いピンクに白い粒が増え、既存の色保持テストが失敗した。単色背景にも粒が出た。
  約6%改善という数値だけでは採用していない。
- 色相・彩度の評価で候補を絞るだけでも、単色背景に新しい色を加えてしまう場合があった。
  比較画像を見て確認し、単色計画を拡張しない条件と背景の回帰テストを追加した。
- Knollの64標本の混色に対し、既存色だけで平均色を改善し、画素の期待誤差も増やさない2回の補正を試した。
  5色距離・linear/sRGB・強度・陰影マスクの計240計画では条件を満たしたが、48の通常画像では
  KnollBayerの総合6.212821→6.218090と悪化し、時間も10.72→16.18ms。
  BlueNoiseの総合は6.254781→6.239058だったが、遠距離誤差はわずかに増え、時間も10.64→16.39ms。
  混色の平均に対する改善を、画像全体の改善とは扱わず、両方式とも元の実装を維持した。
